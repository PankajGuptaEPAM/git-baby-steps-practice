# Calculator

This project provides a simple multiplication function.

## `multiply()`

`multiply(first_number, second_number)` returns the product of two numbers.

```python
from calculator import multiply

result = multiply(6, 7)
print(result)  # 42
```

## Run the demo

Run the demonstration script with Python:

```powershell
python main.py
```

It prints:

```text
6 * 7 = 42
```
